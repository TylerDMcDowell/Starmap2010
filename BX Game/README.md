# BX Campaign System

## Purpose
Persistent campaign with strict file separation and long-term continuity.

## Files

character.md → Player only (full control)
inventory.md → current gear/loadout
items.md → item definitions (not quantities)
rules-lite.md → rulings + mechanics from play

world/npcs.md → party + NPC stats + observed relationships
world/locations.md → locations + status
world/rumors.md → hooks
world/world-state.md → global situation
world/monsters.md → evolving threats

DMs.md → hidden info, maps, escalation (DO NOT REVEAL)
sessions/ → chronological logs

## Update Protocol
After each session update ALL relevant files.
